# Akvaiassociates

Hello World starter configured with Next.js App Router, Tailwind CSS v4, and TypeScript, ready for deployment on Vercel.

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## Scripts

- `npm run dev` — Start the Next.js development server on port 3000
- `npm run build` — Create an optimized production build
- `npm run start` — Serve the production build on port 3000
- `npm run lint` — Run TypeScript type checking

## Deploy on Vercel

Push this repository to GitHub and import it in [Vercel](https://vercel.com/new), or deploy directly from the CLI:

```bash
npx vercel
```
