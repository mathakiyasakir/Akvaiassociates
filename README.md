# Akvaiassociates

Official web application for **Akvai Associates — Architectural Practice**, built with Next.js (App Router), Tailwind CSS v4, TypeScript, Motion, and Lucide Icons, ready for deployment on Vercel.

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

## Scripts

- `npm run dev` — Run the Next.js development server on port 3000
- `npm run build` — Build the production bundle for Vercel
- `npm run start` — Serve the production build on port 3000
- `npm run lint` — Run TypeScript type checking

## Deploy on Vercel

Import this repository directly into [Vercel](https://vercel.com/new) or deploy via CLI:

```bash
npx vercel
```
